# Survey Parser
_It parses surveys!_

Survey Parser is a small python program meant to help me sift through a bunch of survey responses that I collected as part of a research project for one of my psychology classes. I would _really_ hate to score all of these responses manually.

It ingests a `.csv` or `.xlsx` file produced by a Google Forms survey I created, calculates scores and subscores to evaluate respondents' attachment styles and relationship quality scores, and outputs the result in a `.csv`.

...that's it.

I'll use the results to do some statistical calculations, but this program isn't involved in any of that (for now, if ever).
